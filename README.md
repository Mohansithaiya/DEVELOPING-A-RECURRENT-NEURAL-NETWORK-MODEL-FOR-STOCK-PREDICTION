# Recurrent Neural Network for Stock Price Prediction

A time-series forecasting project built with **PyTorch** using a **Recurrent Neural Network (RNN)** to predict stock prices from historical closing price data.

The project demonstrates how an RNN can learn patterns and dependencies from sequential financial data and use them to predict future stock prices.

### What's Inside

* Historical stock closing price data
* Time-series data preprocessing
* RNN model implemented using PyTorch
* Training and loss monitoring
* Actual vs predicted stock price visualization
* Test data predictions
* Performance evaluation through prediction plots

### Built With

**Python · PyTorch · NumPy · Pandas · Matplotlib · Scikit-learn**

### Project Files

The complete implementation, data preprocessing, RNN model, training process, visualizations, and test predictions are available in the uploaded project file.

### Outcome

The RNN model successfully learns patterns from historical stock price sequences and generates predictions for unseen test data. The results are visualized by comparing the true and predicted stock prices over time.
